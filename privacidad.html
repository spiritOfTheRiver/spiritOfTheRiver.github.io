Respaldo Pi — Privacy Policy

Last updated: October 28, 2026

Who uses this app

Respaldo Pi is a personal backup tool used only by its owner to copy files from their Raspberry Pi to their own Google Drive account. It is not offered to the public.

Data accessed

Respaldo Pi accesses Google Drive solely to create, update, list, read and delete the backup files it stores in the owner's Drive. It does not access any other Drive content, any other Google service, or any personal information such as contacts, email or profile data.

How data is used and stored

Files are encrypted on the owner's Raspberry Pi before upload and are stored only in the owner's Google Drive. The OAuth access credentials are stored only on that Raspberry Pi. No data is sent to any server other than Google Drive.

Sharing

No data is collected, sold, shared or transferred to any third party. No data is used for advertising, analytics or to train any model.

Retention and deletion

Backup files remain in the owner's Google Drive until the owner deletes them. Old versions are deleted automatically after 30 days. Access can be revoked at any time from Google Account permissions.

Google API Services User Data Policy

Respaldo Pi's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Política de privacidad (español)

Respaldo Pi es una herramienta de uso exclusivamente personal. Accede a Google Drive solo para crear, actualizar, listar, leer y eliminar los archivos de respaldo de su propietario. Los archivos se cifran antes de subirse y se guardan únicamente en el Google Drive del propietario. No se recopila, vende ni comparte ningún dato con terceros, ni se usa con fines publicitarios o de análisis. El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. Contacto: rios.raspberrypi@gmail.com.
